# 🎮 FlagCapMan

**FlagCapMan** is a creative mix of the classic **Hangman** game and a **Capital City Quiz**!  
In each round, a country's flag is displayed, and your mission is to guess its capital by selecting letters —  
but be careful... with every wrong guess, the glowing red Hangman progresses step by step! ⚡

## 🌐 Live Demo

👉 [Play the Game Here](https://arashsafarighouzhdi.github.io/FlagCapMan/)

---

## 🚀 Features

✨ Sleek red neon theme matching a cyber-style UI  
🏳️ Displays random country flags from a JSON file  
🔠 Interactive letter guessing system (A–Z)  
💀 Six progressive Hangman stages (red neon SVGs)  
📈 Score tracking and win/loss display  
📱 Fully responsive layout  
🎵 Smooth fade and light glow animations

---

## 🧠 How to Play

1. Click **Start Game** to begin.
2. A country flag will appear.
3. Guess letters to reveal the name of the **capital city**.
4. Each wrong guess adds a new stage to the red neon Hangman.
5. Guess the word before the figure completes to score points!

---

## 🧩 Technologies Used

- **HTML5** — Core structure of the game
- **CSS3 (Flexbox + Animations)** — Neon visuals and responsive design
- **JavaScript (ES6)** — Game logic and data handling
- **JSON** — Stores countries and capitals data
